# Trip Simulation - Google Flights Companion Extension

Chrome Extension pendamping untuk menyerok data harga tiket, tanggal, dan maskapai dari antarmuka Google Flights langsung ke aplikasi web **Simulasi Perjalanan**.

## Cara Pasang di Google Chrome:

1. Buka browser **Google Chrome** (atau Microsoft Edge / Brave).
2. Di address bar, ketik:
   ```
   chrome://extensions
   ```
   lalu tekan **Enter**.
3. Di pojok kanan atas, aktifkan saklar **"Developer mode"** (Mode Pengembang).
4. Di pojok kiri atas, klik tombol **"Load unpacked"** (Muat ekstensi yang belum dibongkar).
5. Pilih folder ini:
   ```
   d:\Programs\caesar-portfolio\projects\Trip-Simulation\extension\trip-sim-companion
   ```
6. Ekstensi bernama **"Trip Simulation - Google Flights Companion"** akan langsung aktif!

## Cara Menggunakan:
1. Buka aplikasi **Simulasi Perjalanan**.
2. Klik tombol **"Cek Harga di Search Engine"**.
3. Klik tombol **"Buka di Mini Window"** pada opsi Google Flights.
4. Jendela mini Google Flights akan muncul di samping layar. Pilih tanggal & rute yang Anda mau.
5. Klik tombol hijau **`[ ✈️ Masukkan ke Simulasi ]`** pada tiket pesawat yang Anda pilih.
6. Data harga, tanggal pergi-pulang, dan durasi otomatis terisi di aplikasi web!
